# Super Mario Galaxy Experience

Uma landing page cinematográfica inspirada no universo de **Super Mario Galaxy**, criada como projeto de estudo e portfólio front-end.

O objetivo deste projeto é transformar uma ideia simples de landing page em uma experiência visual mais avançada, usando tecnologias modernas, animações, componentização e boas práticas de desenvolvimento.

---

## Preview

Em breve, este projeto poderá ser publicado na Vercel para visualização online.

---

## Tecnologias utilizadas

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- React Hooks
- Git e GitHub
- GitHub Codespaces

---

## Funcionalidades

- Layout responsivo
- Hero section cinematográfica
- Fundo espacial animado
- Header com menu responsivo
- Cards animados de personagens
- Seção de galáxia com planetas animados
- Modal de trailer
- Contador regressivo real
- CTA final com link para o GitHub
- Organização profissional de componentes
